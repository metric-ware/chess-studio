Music files pair MP3 audio with JSON source metadata and cached analysis. Removing the analysis key recomputes beat/drop data. Analysis uses 22050Hz mono, STFT flux, autocorrelation tempo, dynamic-programming beats, bass-onset downbeat phase, and energy-rise drop candidates. These are timing suggestions: syncopated bass, constant-energy tracks, and half-tempo ambiguity can defeat the detector. The cached energy curve uses an exact 10Hz time base.
Edit maps segment beats and the drop to edit time; drop is given as a source-song time. Near-duplicate beats within 0.1s at a splice merge to the later beat. beat(t, k) is time-based, which avoids index shifts when a first downbeat falls just before an excerpt. Mix applies 12ms fades at excerpt joins and the edit's chosen final fade; edit.mute(t0, t1) silences the music (with a 256-sample ramp) for gaps before a slam. Unused music effects (lowpass sweep, tape stop, stutter) and multi-song segments were removed on 2026-10-07. Waveform measurements use sample timestamps rather than rounded hop durations, which previously accumulated 0.2s error near song 87s.
Known timing facts: HEAVENLY JUMPSTYLE's analyzed drop 49.876 is only a bass re-entry inside a build; its real slam is 51.734, and the 12.957 main drop is accurate. Other tracks: MONTAGEM PERIGOSA Ultra Slowed drifts around song 52.4–56.1; 56.08 is a clean downbeat. MONTAGEM URANIUM opens with four 16th-note ticks (0.020/0.166/0.311/0.457) and a long 808 boom at 0.603 that sustains to about 3s, then a quiet melodic section whose highs fade out 14.0-14.56 before the exact 14.559 drop; that groove breaks at 21.525 into near silence 22.7-23.8, and the audible slam is 23.87 while analysis says 24.45. Its groove bars alternate A/B and correlate 0.83-0.93, so repeating a bar (the Légal trap plays 16.881-19.203 twice) adds time before the break without an audible seam. SEM CONTROLE's main entry is 8.75, its main payoff drop is 17.485, and second drop is 87.307. Its grid is otherwise accurate after accounting for exact sample time. NCS funk bass slams can lead or trail the hi-hat grid by 0.1–0.25s. Fearless Funk's cached analysis was redone at 129.3bpm because automatic 86.25 produced an irregular grid.
Mix uses stereo 44.1kHz float buffers. Export normalization targets -14 LUFS and -1dBTP with two-pass FFmpeg loudnorm; AAC export is 320kbps/48kHz. Chess.com move sounds override synth names. Synth effects are deterministic; a riser ends at full level, so its onset must account for its duration. game_sounds maps Game events (move, capture, castle, check, mate, promote) to sounds.
Song fetching scores yt-dlp search candidates using artist/query matches, Topic channels, duration, and edit/loop/version penalties; the result is not guaranteed to be an official upload. Several existing commercial tracks came from reuploads. Source URLs and uploader metadata remain in assets/music/*.json. web_embedded/mweb clients and Node were used after the default web client encountered rate limiting.
